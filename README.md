# RepChime landing page

A static, multilingual landing page for RepChime. The site is prepared for `https://repchime.app/` and can be hosted on GitHub Pages, Cloudflare Pages, Netlify, or any static web host.

## Locales

- English: `/`
- German: `/de/`
- French: `/fr/`
- French (Canada): `/fr-ca/`
- Spanish (Spain): `/es/`
- Spanish (Mexico): `/es-mx/`

The legal pages remain in the separate `fitreps-legal` repository and are linked from every locale.
